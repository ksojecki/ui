title: DatePicker
description: A date field with a calendar popover. Values are ISO dates (YYYY-MM-DD).
group: forms
components: [DatePicker]
---

`DatePicker` is controlled. `value` and `onChange` use `YYYY-MM-DD` strings, so they fit form state and APIs without conversion. `locale` sets the month names and the first day of the week. Pass translated `previousLabel` and `nextLabel` for the month buttons.
