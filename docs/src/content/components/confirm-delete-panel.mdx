---
title: ConfirmDeletePanel
description: An inline confirmation before a destructive action.
group: feedback
components: [ConfirmDeletePanel]
---

Use it in place of a dialog when the item being deleted is already on screen. Put what will be lost in `warning`. While `saving` is true the delete button shows a spinner; pass `error` if the delete fails.
